# Please read before contributing to this project.

## This project is the creation of humans, not vibe coded slop. 
AI can be used to find bugs, help create drafts of pseudo code, or brainstorm. Humans should be writing the actual code.

## Make sure to keep things clean and organized when contributing. 
Keep to standard c#, xaml, etc naming conventions. Folder naming is camelCase. Break rules if needed.
